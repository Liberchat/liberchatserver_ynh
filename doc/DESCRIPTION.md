# 🚩 Liberchat - Chat Sécurisé & Décentralisé

**Version 6.5.5** - Plateforme de communication libre avec chiffrement de bout en bout, conçue pour la confidentialité maximale et l'accessibilité universelle.

## ✨ Nouveautés Version 6.5.5

### ♿ **Accessibilité Universelle**
- **6 options d'inclusion** : contraste élevé, tailles de police adaptatives, police dyslexie
- **Support lecteurs d'écran** : NVDA, JAWS, VoiceOver, TalkBack
- **Navigation clavier** complète avec raccourcis visuels
- **Conformité WCAG 2.1** niveau AA

### 🎨 **Thèmes Personnalisés**
- **8 thèmes prédéfinis** : Anarchisme, Cyberpunk, Bleu Clair, Vert Solidaire...
- **Créateur de thèmes** : interface intuitive pour créer vos propres styles CSS
- **Aperçu temps réel** des modifications

## 🔒 **Sécurité & Confidentialité**
- **Chiffrement E2E** sur tous les contenus (messages, images, vocaux, réactions)
- **Aucun stockage serveur** - messages jamais sauvegardés
- **Clés de session** temporaires
- **Protection complète** : CSP, CORS, XSS

## 💬 **Communication Avancée**
- **Chat temps réel** avec WebSockets haute performance
- **Messages vocaux** universels (tous navigateurs/mobiles)
- **Réactions emoji** chiffrées sur chaque message
- **Réponses & modifications** avec menu contextuel
- **Indicateur de frappe** en temps réel

## 📁 **Partage Sécurisé**
- **Images E2E** avec aperçu plein écran et zoom
- **Documents** glisser-déposer
- **Liens enrichis** avec prévisualisation automatique
- **Taille configurable** via panneau admin

## 🌐 **Multi-Instance & Flexibilité**
- **Installation multiple** sur même serveur (équipes, projets...)
- **Support multi-domaines** : IP locales, domaines classiques, Tor
- **PWA** : installation sur écran d'accueil mobile/desktop
- **Mode hors-ligne** avec service worker

## 📱 **Interface Moderne**
- **Design responsive** optimisé mobile/desktop
- **Mode sombre/clair** avec basculement instantané
- **Animations fluides** (désactivables pour accessibilité)
- **Sélecteur emoji** intégré et compact

## 🎯 **Cas d'Usage**
- **Communication privée** : famille, amis, couples
- **Équipes professionnelles** : projets sensibles, télétravail
- **Groupes militants** : organisation, coordination sécurisée
- **Réseaux locaux** : entreprises, associations, collectifs
- **Situations critiques** : journalisme, activisme, zones censurées

## ⚡ **Installation Simple**
- **Un clic** depuis le catalogue YunoHost
- **Multi-instance** : `/equipe1`, `/equipe2`, `/famille`...
- **Configuration automatique** : HTTPS, certificats, reverse proxy
- **Panneau admin** intégré pour paramètres avancés
